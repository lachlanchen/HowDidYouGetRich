# How Did You Get Rich? V3

This directory permanently preserves the accepted V3 reader editions:

- [Full-size PDF](how-did-you-get-rich-v3.pdf), 163 pages.
- [Pocket 1.2x PDF](how-did-you-get-rich-v3-pocket-1.2x.pdf), 349 pages at 6x9

The body was accepted on August 26, 2026. Its title page and PDF metadata were
recompiled on October 25, 2026 under the current publication title. Both files
come from one complete TeX manuscript; the pocket edition reflows narrow
displays without shortening the book. See [`SHA256SUMS`](SHA256SUMS) for
verification.
